## 2. 目标（一句话）

> 让 10 Hz 权威 tick 下的全量刷新不再表现为硬跳变：生命/法力/攻血数字平滑补间，手牌/战场的卡牌按身份滑位、新卡入场播放淡入+缩放动画。

## 3. 范围（做什么）

- 新增 `Card.Presentation.Battle.Feedback.NumberTween`（纯 C#，无 Unity 依赖）：
  - `To(int target)`：向目标补间（首次调用自动 Snap，不从 0 播放）；`Snap(int value)`：立即到位；`Tick(float dt)`：推进；`Current` / `IsPlaying` / `HasValue`。
  - 线性插值 + 四舍五入取整；中途重定目标从当前值续播（无跳变）。
- 新增 `Card.Presentation.Battle.Feedback.CardMotionView`（MonoBehaviour，仿 CardFadeOutView 惰性取组件）：
  - `MoveTo(Vector2 target)`：anchoredPosition 位置插值；重复调用从当前位置续播。
  - `BeginEntry(Vector2 target)`：进场动画——位置立即落槽，alpha 0→1 + localScale 0.8→1 补间。
  - `Stop()`：无条件复位（scale=1、alpha=1、中止补间）——复位契约入口。
- 新增 `Card.Presentation.Battle.CardZoneSync`（internal 静态，仿 CardListLayout）：
  - 按 `InstanceId` 把区子视图与数据对齐：命中视图原地保留（滑位交由布局），未命中数据租新视图（登记 entering），多余视图还池。牌背（InstanceId=null）同样按位对齐。
- 数值 Tween 接线：`HeroView`（生命补间；护甲/上限立即刷新）、`ManaView`（当前法力补间；上限立即刷新）、`CardView`（同 InstanceId 原位更新时攻/血补间，复用/首次 Snap）。
- 位置插值接线：`CardListLayout.Layout` 增加运动感知——子视图带 `CardMotionView` 时入场走 `BeginEntry`、存量走 `MoveTo`，否则保持旧的原地传送（兼容既有测试与热座场景）。
- 复位契约：`CardView.SetData` 与 `CardViewPool.ResetView` 纳入 `CardMotionView.Stop()`（M6-T5"复用即全量复位"）。
- 生产接线：`BattleUiPrefabs.BuildCardPrefab` 挂载 `CardMotionView`（一处 AddComponent）。

## 4. 明确不做（防止范围蔓延）

- 不做缓动曲线/时长配置化（内部常量，M9 打磨动画手感）。
- 不做"从牌库飞入手牌"的跨区域飞行动画（进场=落位 pop：淡入+缩放）。
- 不做抽牌翻牌、回合横幅、伤害数字改造（M5-T6 已有反馈通道）。
- 不做 PVP 场景装配接线（M14-T3）；`PendingActionFeedback` 不改动。
- 不做 pending 视觉与布局插值的联动策略——登记 P3 观察项 M14-T2-L1，M14-T3 装配时统一处置。
- 不在 `Card.Network` 落位 Docs/05 §3.4 所列 `ViewInterpolator` 组件名——铁律 12 禁止 `Card.Presentation` 引用 `Card.Network`，插值原语必须住 Presentation 供视图消费（设计决策，见结论）。

## 5. 接口约定

```csharp
// Card.Presentation.Battle.Feedback
public sealed class NumberTween   // 纯 C#
{
    public NumberTween(float duration);            // 秒，>0
    public int Current { get; }                    // 显示值（整数）
    public bool HasValue { get; }                  // 是否已被赋值
    public bool IsPlaying { get; }
    public void Snap(int value);                   // 立即到位并停
    public void To(int target);                    // 首次自动 Snap；中途调用从 Current 续播
    public void Tick(float dt);                    // 线性推进；结束停且 Current==target
}

public sealed class CardMotionView : MonoBehaviour
{
    public bool IsPlaying { get; }
    public void MoveTo(Vector2 target);            // 位置插值（已在目标位则立即完成）
    public void BeginEntry(Vector2 target);        // 淡入+缩放入场，位置即落槽
    public void Stop();                            // 无条件复位：scale=1、alpha=1、停
}

// Card.Presentation.Battle
internal static class CardZoneSync
{
    // 按 InstanceId 对齐 children 与 cards；rent 租新视图（计入 entering），recycle 还池。
    public static void Refresh(
        List<CardView> children,
        IReadOnlyList<ICardViewData> cards,
        Func<CardView> rent,
        Action<CardView> recycle,
        out HashSet<CardView>? entering);
}

internal static class CardListLayout
{
    // entering 非空且子视图带 CardMotionView → BeginEntry；带 CardMotionView → MoveTo；否则旧原地赋值。
    public static void Layout(IReadOnlyList<CardView> children, float spacing,
        IReadOnlyCollection<CardView>? entering = null);
}
```

### 设计决策备注

- **ViewInterpolator 不落 `Card.Network`**：铁律 12 禁止 `Card.Presentation` 引用 `Card.Network`，而插值原语的唯一消费者是视图；Docs/05 §3.4 的组件名按职责落位 Presentation（`NumberTween`/`CardMotionView`），网络层未来只传数据不传动画。
- **身份对齐（InstanceId swap）而非索引对齐**：旧 `SetCards` 按索引复用，中段增删时幸存卡错位、新卡占旧槽——整列重绘无法表达"滑位"。`CardZoneSync` 命中即 swap 保留原视图，滑位/进场语义才能成立。
- **兼容降级而非断言**：`CardListLayout` 对无 `CardMotionView` 的视图保持旧的 localPosition 直赋——既有测试与热座场景零破坏，运动组件是可选增强而非硬依赖。
