## 2. 目标（一句话）

> 让回放可复盘：① 每帧显示操作日志（出了什么牌/攻击了谁/英雄被伤害）② 明牌视角看对手手牌（事后复盘无隐藏信息泄露风险）③ 主菜单加"查看回放"按钮脱离 Unity 编辑器。

## 3. 范围（做什么）

### 3.1 操作日志（2_Application 暴露 + 5_Bootstrap 接线）

- `ReplayPlayer` 新增 `AllEvents` 属性（`IReadOnlyList<GameEvent>`，引用 `_controller.Events` 活视图）——纯 BCL，零额外字段。
- `ReplaySceneBootstrap`：
  - 新增字段 `_lastLoggedEventCount`，维护"已投递到 Log 的事件序号上限"。
  - `RenderCurrent()` 内：帧变化时按"前进 1 帧=增量投递 / 跳转=清空+全量重投"规则把 `AllEvents[_lastLoggedEventCount..]` 逐条 `BattleLogView.Append(e)`。
  - `LoadReplay` / `SeekTo` / `StepBy` / 重播路径：交由 `RenderCurrent` 统一处理（跳转=非 +1 帧→自动走清空+全量重投分支）。

### 3.2 明牌视角（5_Bootstrap 表现层）

- `BattleViewSynchronizer` 构造新增 `bool observerMode = false`（默认值不破坏既有调用）。
- `PushPlayer`：`bool showFace = isLocal || _observerMode;`——observer 模式下双方手牌都显示真实 `CardViewData`。
- `ReplaySceneBootstrap` 构造 `BattleViewSynchronizer` 时传 `observerMode: true`。
- `BattleSceneBootstrap`（产品对战）不传 → 默认 false，**PVE/PVP 对战裁剪逻辑零改动**。

### 3.3 客户端入口（5_Bootstrap 主菜单）

- `MainMenuBootstrap` 新增 `CreateReplayButton` → `SceneManager.LoadScene("Replay")`。
- 常量 `ReplaySceneName = "Replay"`（场景已由 M15SceneSetup 写入 Build Settings）。

### 3.4 测试

- `ReplayPlayerEventsTests`（kernel 纯 BCL，`7_Tests/EditMode/Replay/`）：≥ 4 例。
- 明牌视角 Presentation 测试（`7_Tests/EditMode/Bootstrap/`）：≥ 2 例。

## 4. 明确不做（防止范围蔓延）

- **不改规则层**（`MatchController`/`RuleEngine`/`MatchFactory` 零改动；`AllEvents` 只读引用现有 `controller.Events`）。
- **不改产品对战裁剪逻辑**（`BattleSceneBootstrap` 不传 observerMode，PVE/PVP 手牌可见性不变）。
- **不做联机回放**（M15-L1 后置，PVP 命令在 MatchHost 权威侧，需权威层截获）。
- **不做观战实时旁观**（M15-T2 范围；回放明牌 ≠ 实时旁观他人对局，无隐藏信息泄露风险）。
- **不改 BattleLogFormatter**（12 类事件映射已齐全，复用现有 `BattleLogView.Append(GameEvent)`）。
- **不引入第三方库**。
