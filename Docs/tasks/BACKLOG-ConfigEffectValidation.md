## 2. 目标

> CardDatabase 构建时**一次性全量校验**所有启用卡牌的效果表达式可解析、语义合法，把运行时 `ArgumentException` 前移为启动期配置错误报告（一次报全、带卡牌 key 定位）。

## 3. 做什么

- `CardDatabase` 构建期遍历全部启用卡牌，对每张卡的 `Effects` 列表调用 `EffectParser.Parse`（或等价轻量校验）。
- 校验失败不抛首错即停：收集全部错误（卡牌 key + 表达式 + 原因），汇总为一条 `ConfigValidationException`（或等价聚合异常）抛出；`GameLog` 输出完整清单。
- 覆盖三类历史实证错误：
  1. 效果类型名不存在（GainManaEffect、DrawEffect 别名漂移）；
  2. 参数格式/数量/取值非法（SummonEffect 需要 CardKey/Count）；
  3. Trigger 前缀合法但语义可疑可另列 Warn（可选：无前缀默认 OnPlay 是合法设计，不报错）。
- EditMode 测试：坏配置（未知类型/坏参数/坏前缀）建库时失败且错误信息含卡牌 key；好配置全量通过。

## 4. 明确不做

- 不校验效果**语义平衡**（数值强度、胜负影响——属 M9-T3 平衡跑分）。
- 不做 CSV/Excel 导入侧的编辑器校验（M2 管线既有校验保持现状，本任务只管运行时建库契约）。
- 不改任何既有效果行为与配置数据。
