## 2. 目标（一句话）

> 当掉线/房主退出/连接失败发生时，玩家能在 UI 上看到明确的中文原因，并一键返回主菜单——不卡在"等待中"黑屏。

## 3. 范围（做什么）

- **加入方（成员）掉线监视**：成员侧 `NetMatchDriver` 有 `IsConnected` + 心跳状态，新增 `MemberDisconnectWatch` 把"连接断开 / 重连成功 / 终局"翻译为战斗日志 + 胜负面板上的原因行（复用 `DescribeNetEnd` 风格）
- **终局面板增强**：现有 `ShowNetEnd` 胜负面板已有"再来一局"按钮（重载场景回大厅），加一个"返回主菜单"按钮（`SceneManager.LoadScene(MainMenuBootstrap.MainMenuSceneName)`）；正常终局也显示这两个按钮
- **连接失败提示**：大厅阶段连接失败时，当前只在 `PvpLobbyUi.StatusText` 写了一行红字——同步追加到战斗日志（或在大厅 UI 上更醒目），让玩家一眼看见"房主未启动 / 端口不对 / 连接被拒绝"
- **HotSeat/PVE 也加"返回主菜单"**：当前 HotSeatHandler 胜负面板只有"再来一局"——加返回主菜单按钮，异常时也能撤

## 4. 明确不做（防止范围蔓延）

- 不做弹窗系统（Canvas 分层/栈管理是 FR-9.3，属 M8 元游戏内容；本任务复用现有 VictoryPanel + ErrorPanel + 战斗日志）
- 不做断线重连倒计时 UI（HostPeerWatch 日志已有"约 30 秒后判负"文字，精确倒计时属 PVP 深度打磨）
- 不做中途主动退赛按钮（本阶段只有自然异常终局，投降 UI 属 T7 之外）
- 不做"再来一局"房主自动重建（重载场景回大厅后手动点"创建对局"即可，自动重建复杂且易出错）

## 5. 接口约定

```csharp
// 新增：MemberDisconnectWatch（5_Bootstrap/Battle/Net，类比 HostPeerWatch）
internal sealed class MemberDisconnectWatch
{
    public static MemberDisconnectWatch? TryCreate(NetMatchDriver? driver, BattleUi ui);
    public void Pump(); // 每帧：IsConnected 状态翻转 → 日志提示
}

// BattleSceneBootstrap.Net：ShowNetEnd 加返回主菜单按钮
private void ShowNetEnd(string? overrideText = null)
{
    // 现有：VictoryPanel + VictoryLabel + OnNetPlayAgain
    // 新增：OnNetReturnToMain → SceneManager.LoadScene(MainMenuBootstrap.MainMenuSceneName)
    _ui.VictoryButton.onClick.AddListener(OnNetReturnToMain); // 第二按钮
}

// PvpLobbyFlow：连接失败时日志提示（非阻断，补充现有 StatusText）
private void OnNetConnectFailed(string msg)
{
    _ui.SetStatus("!连接失败：" + msg); // 现有
    BattleLogView.AppendText("!连接失败：" + msg); // 新增
}
```

## 6. 验收标准（必须可测）

| 编号 | 场景 | 期望结果 |
| --- | --- | --- |
| AC-1 | 房主正常终局（一方英雄归零） | 胜利面板显示胜者座位 + "再来一局" + "返回主菜单"两个按钮 |
| AC-2 | 房主退出（主动关闭 exe） | 成员侧胜利面板显示"对局作废（房主已退出）" + "返回主菜单"按钮；房主侧也显示"（房主已退出）" |
| AC-3 | 成员掉线（拔网线/关闭 exe） | 房主侧战斗日志提示"对手已断线，等待重连（约 30 秒后判负）"；30 秒后胜利面板显示"对手掉线判负" + 返回按钮 |
| AC-4 | 成员重连成功 | 房主侧战斗日志提示"对手已重连，对局继续"，胜利面板不弹出 |
| AC-5 | 成员侧连接断开 | 成员侧战斗日志提示"与房主连接断开"；若终局原因是 Disconnect/HostQuit，胜利面板显示 |
| AC-6 | 大厅连接失败（房主未启动 / 端口错误） | 大厅 StatusText 红字 + 战斗日志同步追加"!连接失败：…" |
| AC-7 | HotSeat/PVE 胜负面板 | 同样有"再来一局" + "返回主菜单"两个按钮 |
| AC-8 | 胜负面板按钮不重复绑定 | ShowNetEnd 只被调一次，点击按钮不抛异常 |
