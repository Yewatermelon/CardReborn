## 2. 目标（一句话）

> 基于已有 `MatchRecording`/`MatchReplayer`（M4-T9 一次性全量重放），扩展为**可暂停/倍速/帧跳转**的交互式回放系统，并接入持久化（写盘+列表+加载）与回放场景 UI。

## 3. 范围（做什么）

### 3.1 持久化接线（2_Application，纯 BCL）

- `ReplayFileRepository`（`Assets/_Project/2_Application/Replay/`）：
  - `Save(MatchRecording, string dirPath)` → 写入 `<时间戳>-<seed>.json`，返回文件路径
  - `List(string dirPath)` → `IReadOnlyList<ReplayFileMeta>`（文件名/seed/命令数/时间戳）
  - `Load(string filePath)` → `MatchRecording`
  - `Delete(string filePath)` → bool
  - 纯 BCL（`System.IO`）；不依赖 UnityEngine
- 对局结束接线（`5_Bootstrap`）：`BattleSceneBootstrap` 终局时调用 `ReplayFileRepository.Save` 写到 `Application.persistentDataPath/Replays/`

### 3.2 播放控制器（2_Application，纯 BCL）

- `ReplayPlayer`（`Assets/_Project/2_Application/Replay/`）：
  - 构造：`ReplayPlayer(MatchRecording recording, CardDatabase database)`
  - 状态机：`Idle | Playing | Paused | Finished`
  - 方法：`Play()` / `Pause()` / `Step()`（前进一步，到终局返回 false）/ `Seek(int frame)`（跳到任意帧）/ `SetSpeed(float)`（1x/2x/4x）
  - 属性：`CurrentFrame` / `TotalFrames` / `State` / `CurrentSnapshot`（当前帧的 `MatchState` 快照）/ `Speed`
  - 实现本质：把 `MatchReplayer.Replay` 的"逐命令 Submit"做成**可暂停迭代器**——用 `MatchFactory.Create` 重建初始状态，按帧推进 `MatchController.Submit`；`Seek` 用"重建+快进到目标帧"实现（**不做状态差量回退**，简单可靠）
  - 纯 BCL；驱动节奏由表现层（`5_Bootstrap`）用协程/`Update` 调用 `Step()` 控制，`SetSpeed` 只改 `Speed` 属性、不改内核推进逻辑

### 3.3 回放场景 UI（5_Bootstrap）

- 复用 M6-T1 模式：Editor 菜单生成场景 + 运行时代码建 UI + Bootstrap `Start` 自包含初始化
- **禁用命令上行**（回放只读，不上行 `GameCommand`）
- 控件：进度条（`Slider`）+ 播放/暂停按钮 + 上一步/下一步按钮 + 倍速切换（1x/2x/4x）
- 流程：从 `ReplayFileRepository.List` 选择文件 → `Load` → `ReplayPlayer` 驱动 → 复用 Battle 场景的 View 体系渲染 `CurrentSnapshot`
- 入口：主菜单/结算页"查看回放"按钮（可后置，先做场景内自启动）

### 3.4 EditMode 测试

- `ReplayFileRepositoryTests`：Save/List/Load/Delete 往返 + 边界（空目录/不存在文件/损坏 JSON/重复 Save 幂等）
- `ReplayPlayerTests`：8+ 用例（详见 §6/§7）

## 4. 明确不做（防止范围蔓延）

- **不做观战模式**（M15-T2，下一任务）
- **不做 30 秒延迟防窥探**（商业化扩展点，简历可写"预留"，不实现）
- **不做回放文件分享/上传/加密/压缩**
- **不改规则层任何行为**（`MatchController`/`RuleEngine`/`MatchFactory` 零改动）
- **不引入第三方库**
- **不做回放内交互**（回放中不能出牌/攻击，只读）
- **不做状态差量回退**（`Seek` 用"重建+快进"实现，不做复杂的反向回退）

## 5. 接口约定

```csharp
// 2_Application/Replay/ReplayFileRepository.cs（Card.Application.Replay，纯 BCL）
public sealed class ReplayFileRepository
{
    public string Save(MatchRecording recording, string dirPath);   // 返回写入的文件路径
    public IReadOnlyList<ReplayFileMeta> List(string dirPath);
    public MatchRecording Load(string filePath);
    public bool Delete(string filePath);
}

public readonly struct ReplayFileMeta
{
    public string FilePath { get; }
    public int Seed { get; }
    public int CommandCount { get; }
    public DateTime CreatedAt { get; }
}

// 2_Application/Replay/ReplayPlayer.cs（Card.Application.Replay，纯 BCL）
public sealed class ReplayPlayer
{
    public ReplayPlayer(MatchRecording recording, CardDatabase database);
    public ReplayPlayerState State { get; }      // Idle/Playing/Paused/Finished
    public int CurrentFrame { get; }
    public int TotalFrames { get; }
    public MatchState CurrentSnapshot { get; }   // 当前帧状态快照
    public float Speed { get; }                 // 1/2/4
    public void Play();
    public void Pause();
    public bool Step();                          // 前进一帧，到终局返回 false
    public void Seek(int frame);                 // 跳到任意帧（0..TotalFrames）
    public void SetSpeed(float speed);
}

public enum ReplayPlayerState { Idle, Playing, Paused, Finished }
```

## 6. 验收标准（必须可测）

| 编号 | 场景 | 期望结果 |
| --- | --- | --- |
| AC-1 | `ReplayFileRepository.Save→List→Load→Delete` 往返 | List 能见到刚保存的文件；Load 还原的 `MatchRecording` 与原一致（seed/seat/commands）；Delete 后 List 不再见 |
| AC-2 | `ReplayPlayer.Play` 至终局 | `CurrentFrame == TotalFrames`；`State == Finished`；`CurrentSnapshot` 与 `MatchReplayer.Replay` 的 `FinalState` 一致 |
| AC-3 | `Pause` + `Step` 单步推进 | 每次 `Step` 后 `CurrentFrame +1`；`CurrentSnapshot` 与全量重放到该帧一致 |
| AC-4 | `Seek(任意帧)` | `CurrentFrame == 目标帧`；`CurrentSnapshot` 与全量重放到该帧一致 |
| AC-5 | `Seek` 边界（0 / TotalFrames） | `Seek(0)` 回到初始状态；`Seek(TotalFrames)` 到终局 |
| AC-6 | 空录制（0 命令） | `TotalFrames == 0`；`Play` 直接 `State == Finished` |
| AC-7 | 跳到被拒绝帧 | `CurrentSnapshot` 状态零变更（与 `MatchStepRecord.Accepted==false` 一致） |
| AC-8 | 静态门禁与覆盖率 | `check.ps1` PASS；`coverage.ps1` 门禁 `0_Core≥90%` / `Domain+App≥80%`；kernel 全绿 |
| AC-9 | Unity EditMode 编译通过 | 新增测试文件在 Unity 编译无错（用户手动跑 Test Runner 留证） |
