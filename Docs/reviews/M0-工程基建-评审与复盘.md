## 4. 问题与根因（5 Why）

现象：PlayMode 冒烟测试在提交时无法编译（`CS0103`）。

- Why1：`SmokeTests.cs` 漏了 `using UnityEngine`。
- Why2：该类测试写完后没有在 Unity 里真正跑过一次就提交了。
- Why3：当时不存在"提交前必须有一次 Unity 侧编译+测试证据"的强制环节。
- 根因：**缺少机器可读的验证闭环**（AI 看不到 Console）。

改进：本轮已落地桥接层（`AgentConsoleBridge` / `AgentTestBridge`），并把"提交前必须有 `Logs/agent-status.json` 0 error 与 `Logs/agent-tests.json` 0 failed"写进 [06 §7.3](../06-新项目搭建与仓库初始化清单.md)。

现象：文件改动后 Unity 长时间不重新导入（14:02 写入 → 17:05 才编译）。

根因：编辑器的资产重导入依赖窗口获得焦点，而桥接层只提供菜单入口，没有"无界面触发"通道。改进：见 M0-R2。
